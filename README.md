# PYTHON STACK

A collection of Python-based utilities focused on system monitoring, API monitoring, automation, and backend tooling.

## Projects

### 1. SYS WATCH

A lightweight system monitoring utility for tracking:

- CPU usage
- Memory usage
- Disk usage
- System boot time
- Active processes
- JSON report export

**Technologies:**
- Python
- psutil
- JSON

---

### 2. API MONITOR

A command-line API monitoring utility for checking:

- API availability
- HTTP status codes
- Response times
- Error handling
- JSON log generation

**Technologies:**
- Python
- requests
- JSON
